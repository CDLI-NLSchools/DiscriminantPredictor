# Discriminant Predictor

A practice app for **Math 2201, Unit 3 — Quadratic Equations** (Section 3: the discriminant).

Each round deals a quadratic equation — sometimes in standard form, sometimes in an unexpanded form the student has to standardize mentally. The student predicts how many real roots it has (0, 1, or 2), then the reveal shows the discriminant worked out and the parabola graphed from the same coefficients, with the intercepts marked. Cases rotate in a balanced mix, and every equation is generated fresh, so practice never runs out.

Single-file HTML (`index.html`), no external resources — runs offline once loaded.
